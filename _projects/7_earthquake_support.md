A location-aware web and mobile application that surfaces nearby earthquake support resources for users in affected areas.

- **Front end.** React, with geolocation to detect the user's region and personalize results.
- **Back end.** Spring Framework REST API serving emergency-support data.

**Stack.** Spring Framework · React · Java.
