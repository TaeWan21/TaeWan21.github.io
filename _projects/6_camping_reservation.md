A web application for reserving campsites, built end-to-end as a learning project for full-stack JavaScript.

- **Front end.** React-based reservation flow with search, availability, and booking confirmation views.
- **Back end.** Express.js REST API with persistent reservation storage.

**Stack.** React · Express.js · Node.js.
