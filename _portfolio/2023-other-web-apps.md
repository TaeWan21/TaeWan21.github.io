A few additional applied projects built while learning full-stack and desktop development.

**Camping Site Reservation Web Application**
- Built a campsite reservation flow with **React** on the front end and **Express.js** on the back end.

**Earthquake Support Web/App, Location-Aware**
- A location-aware service that surfaces nearby earthquake support resources for users.
- **Spring Framework** back end with a **React** front end.

**Smart Note with Generative AI**
- A desktop note-taking app on **WPF (C#)** that uses generative AI to assist note authoring (summarization, expansion, structuring).
